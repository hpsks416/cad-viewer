# 学习笔记：Simate 的 Physical AI 研发方法论 → cad-viewer 映射

> 来源：量子位《AI开始研究Physical AI：FSD级团队亮出首版模型Simate-beta，空降RoboDojo》
> https://www.qbitai.com/2026/09/498271.html （微信原文：https://mp.weixin.qq.com/s/BFSJvvz-fTIj7GoBn8G0Zg）
> 记录：本项目会话

## 一句话

前 Tesla-FSD 级团队（Simate / Silicon Mate）成立三个月推出首版通用物理「快系统」Simate-beta，登顶 RoboDojo。可借鉴的不是 VLA / 世界模型那套模型技术，而是它的**研发方法论与系统架构**。

## 可迁移要点 → 本项目映射

1. **快系统 / 慢系统拆分**
   - 文章：慢系统做高层规划，快系统做毫秒级实时反应；Simate 把快系统参数做大探索零样本。
   - 映射：cad-viewer 已是「离线重 / 在线轻」——慢系统（OCP 解析 STEP → Blender 导出 glb，分钟级）+ 快系统（three.js 浏览器实时渲染交互）。文章给这条架构做了外部背书。

2. **可插拔、AI 可读的模块化（SiPAI）**
   - 文章：模块边界 / 接口 / 配置 / 验证定义清晰，Agent 才知道改哪、影响什么、怎么验证。
   - 映射：本项目已配置驱动（`tools/config.json`、`assets/convert-presets.json`、`materials/presets.json`、`naming-map.json`），模块边界清晰（`viewer/*.js`、`tools/*.py`）。

3. **仿真优先的高频筛选（AI-native Infra）**
   - 文章：先「世界模型 + 仿真」快速淘汰无效方向，只把有潜力的上真机。
   - 映射：本项目 `--no-preview` / 低清缩略图已是「便宜的先筛」；新增「快速预览」粗网格预设，先低清验证层级 / 材质再全量 PBR。

4. **动态研究上下文 + 实验自动化（AutoResearch）**
   - 文章：把代码 / 数据配比 / 历史实验日志 / 评测反馈汇成实时 Context，「成果变成下一轮生产资料」。
   - 映射：本项目「批量导出 + 多预设」已有雏形；新增「转换历史」沉淀（预设参数 / 耗时 / 产物大小），支撑结果对比与复用。

5. **迭代吞吐 > 单次完美**
   - 文章：三个月登顶靠「单位时间验证更多假设」。
   - 映射：M1→M5 里程碑 + batch 工具化即此思路；新增「改预设→重导出→看效果」一键闭环（转换完自动加载新模型）。

## 不直接适用（诚实标注）

4D 物理感知、分层时序记忆、VLA / 世界模型、RSI 训练——这些是具身智能 / 机器人学习的模型技术，与「CAD 可视化管线」不直接相关。但「4D = 空间结构 + 时间动态」可映射到本项目的查看维度：静态结构（剖切 / 场景树 / 爆炸）+ 动态时序（关节动画 / 驾驶 / FPV）。
